AI議事録 音声入力

このページは、Google Apps Scriptのサイドバー内ではマイク許可が得られないため、 GitHub Pages（Google以外のドメイン）に独立して用意した音声入力用ページです。

設定（初回のみ）

値はこのブラウザの localStorage にのみ保存されます（サーバーには送信されません）。 次回以降、このページを開いたときは自動的に読み込まれます。

未使用のブラウザで確認中です…

対象のスプレッドシート・シートは、スプレッドシート側の「AI議事録」→「音声入力ページを開くリンクを表示」から開いた場合のみ自動設定されます。 直接このページを開いた場合は、URLの末尾に ?ss=スプレッドシートID&sheet=シート名 を付けてアクセスしてください。
